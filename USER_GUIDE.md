# GlamBook User Guide

## Customer workflow
1. Open `index.html`.
2. From Home, choose **Book Appointment**.
3. Enter your full name and phone number.
4. Optionally enter an email address.
5. Choose a salon service.
6. Select an appointment date. Past dates are not accepted.
7. Choose one of the available time slots.
8. Review the price, duration, date, and time in Booking Summary.
9. Press **Confirm appointment**.
10. Save the booking reference shown in the confirmation window.
11. Open **My Bookings** to search for the booking, view details, or cancel it.

## Admin workflow
1. Open **Admin**.
2. Sign in with the demo credentials in README.md.
3. In **Appointments**, search records and change the status to Pending, Confirmed, Completed, or Cancelled.
4. Use **Delete** only when a record should be permanently removed; confirm the prompt.
5. Open **Services** to add a service, edit an existing service, or delete a service.
6. Log out after the demonstration.

## Responsive use
The navigation changes to a compact menu on small screens. Forms, cards, and management sections adapt to phone, tablet, and desktop widths.

## Data storage note
LocalStorage is specific to the browser and device. A booking created on one phone will not automatically appear on another phone or on the admin's computer. Use the same browser/device for the demonstration, or explain this limitation during the presentation.
